# 接口清单 · workbuddy-wallpaper

> **本文件由 `scripts/gen-api-docs.js` 从 `server/routes.js` 的 `ROUTES` 表生成，不要手改。**
> `verify.js` 会比对生成结果与磁盘文件，不一致即失败（防止文档漂移）。
>
> 鉴权口径：标注 **是** 的接口为受保护路径，必须带请求头 `x-wbwp-token`；
> 令牌在 `<数据目录>/.api-token`。同时校验 `Origin`：允许 `file://`（注入页）与同源，其余 403。
> 服务只监听 `127.0.0.1`。

| 方法 | 路径 | 说明 | 需令牌 | 参数 | 返回 |
|---|---|---|---|---|---|
| `GET` | `/api/wallpaper/health` | 健康检查：版本、挂载方式、数据目录、渲染器状态 | 否 | — | ok / plugin / dirs / renderer |
| `GET` | `/api/wallpapers` | 列出官方壁纸（随包种子） | 否 | — | wallpapers[]：name/type/title |
| `GET` | `/api/custom-wallpapers` | 列出用户上传的自定义壁纸 | 否 | — | wallpapers[] |
| `POST` | `/api/custom-wallpapers` | 上传自定义壁纸（图片） | 否 | body：图片二进制或 dataURL | name / size |
| `DELETE` | `/api/custom-wallpapers` | 删除指定自定义壁纸 | 否 | query：name | ok |
| `GET` | `/api/we-wallpapers` | 列出 Wallpaper Engine 库（含缓存） | 否 | query：refresh=1 可强刷 | items[]：id/title/type/size |
| `POST` | `/api/we-apply` | 应用某个 WE 壁纸（场景/视频） | 否 | body：id / options | ok / applied |
| `GET` | `/api/we-properties` | 读取场景可调属性（project.json 的 general.properties，供面板生成控件） | 否 | query：weId | properties[]：key/text/type/value/min/max/options |
| `POST` | `/api/we-properties` | 应用场景属性（落盘 weUserProperties 并重注入） | 否 | body：id / properties{key:value} | ok / applied / properties |
| `POST` | `/api/theme-bg` | 设置主题背景（图片/视频/场景三选一） | 否 | body：type / id / opacity | ok / applied |
| `POST` | `/api/inject` | 手动重新注入页面 UI（注入丢失时的自救入口；需注入器在运行） | 是 | —（无请求体） | ok / injection{ok,at,attempts,lastError} |
| `POST` | `/api/pause` | 暂停/恢复壁纸（可逆：只拆/铺背景层，服务与看门狗照跑；与 /api/shutdown 的 .stopped 无关） | 是 | body：paused=true|false | ok / paused / applied（false 表示无注入通道，状态已存但页面不变） |
| `GET` | `/api/mask` | 读取当前蒙版浓度 | 否 | — | opacity |
| `POST` | `/api/mask` | 设置蒙版浓度（0–1） | 否 | body：opacity | ok / opacity |
| `GET` | `/api/fonts` | 枚举本机已装字体（面板字体页的数据源） | 否 | — | fonts[] |
| `GET` | `/api/update` | 读缓存中的更新状态（**不发网络**，面板打开即用） | **是** | — | currentVersion / latest / hasUpdate / mustUpdate / canUpdate / notes |
| `POST` | `/api/update/check` | 强制检查更新（访问 feed） | **是** | body：force=true | 同 GET /api/update |
| `POST` | `/api/update/apply` | 下载并应用更新（验签 → 备份 → 覆盖 → 重启） | **是** | body：expectVersion | ok / version / from / backup / zipSha256 / restart |
| `POST` | `/api/update/rollback` | 回滚到备份版本（受 minSupported 降级护栏限制） | **是** | body：version | ok / version / written / removed |
