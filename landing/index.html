安装（三步）

  1. 下载并解压压缩包
  2. 双击里面的 install.cmd（中文名 一键安装.cmd）
  3. 按提示走完 —— 它会自己找 Node、装好、注册开机自启，并检查一个关键开关

之后打开 WorkBuddy，壁纸就会自己出现。想临时用一下不装进系统？双击 启动.cmd 即可。

⚠️ 最容易卡住的一步：调试端口

本工具是"注入"进 WorkBuddy 界面的，所以 WorkBuddy 必须带调试端口启动， 否则会出现「装了但什么都没发生」——服务在跑、日志正常、屏幕上却没动静。

好消息：install.cmd 会自动检测这一点，没开就直接问你"要不要我帮你改快捷方式"。 改的是快捷方式文件本身（改前自动备份），不会去动任何正在运行的程序。

改完要完全退出 WorkBuddy（托盘图标也退掉）再用那个快捷方式打开 —— 它是单实例应用，已经在跑的时候再点快捷方式，新参数会被忽略。

常见问题

Windows 弹出"已保护你的电脑"，怎么办？

因为安装包没有购买代码签名证书（个人开源项目负担不起）。点「更多信息」→「仍要运行」即可。 如果下载的 .cmd 双击没反应，右键 → 属性 → 勾选底部的「解除锁定」。

提示找不到 Node？

脚本会优先用 WorkBuddy 自带的 Node（≥22），找不到才回退系统 PATH。 如果两条路都没有：先打开一次 WorkBuddy 让它准备好内置运行时，再重跑一次安装脚本。 Node 必须 ≥ 22 —— 低版本的表现很隐蔽：服务正常，但界面永远不出来。

装了却没反应，怎么排查？

在解压目录执行 node scripts\companion.js --status，它会输出四行诊断。 第 4 行 CDP 9222 如果是「未监听」，就是上面那个调试端口的问题 —— 按它的提示走即可（也可以直接跑 node scripts\fix-shortcut.js 自动修）。

怎么卸载？

双击 uninstall.cmd（或 一键卸载.cmd）。它会依次： 优雅摘掉页面注入 → 停服务 → 停看门狗 → 撤销开机自启 → 删安装目录 → 然后问你要不要连数据目录一起删（里面有你自己上传的壁纸，默认保留）。

安全吗？它会改我系统里什么？

它不修改 WorkBuddy 安装目录。会碰的东西只有三处，且都可撤销： ① 你自己目录下的技能文件夹；② 开机启动项（一个 vbs，卸载时删除）； ③ 只有在你同意时才改 WorkBuddy 快捷方式（加调试参数，改前备份）。

WorkBuddy 升级后壁纸突然没了？

常见两种原因：① 升级重启丢了调试端口参数 —— 用改过的快捷方式重开即可； ② 界面类名变了，导致透明化规则失效。跑 node scripts\doctor.js 能列出哪些锚点失效了。
